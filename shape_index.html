CSS Shapes · Demostración visual

Haz que el texto fluya alrededor de formas reales.

shape-outside

La base de todo flujo con formas

Esta propiedad solo funciona en elementos flotados. El contorno externo del float define por dónde puede pasar el texto, y ahí es donde entran circle(), ellipse(), inset(), polygon(), url(), más shape-margin y shape-image-threshold como complementos de shape-outside.

Demostración base sin shape-outside

Forma normal — sin shape-outside

Este es el estado base: una tarjeta rectangular normal y el texto siguiéndola como cualquier bloque flotado.

Aquí todavía no se está usando ningún tipo de shape-outside. El texto choca contra el borde recto del bloque.

01

circle()

Ejemplo con circle()

Uso clásico: una foto de perfil. Con circle() el texto fluye de forma natural alrededor del rostro, evitando los huecos vacíos que dejaría un cuadrado.

En este ejemplo, usamos img/profile1.png para demostrar cómo una imagen cuadrada se convierte visualmente en un avatar circular mientras el texto se adapta a su contorno.

/* Bloque base en shape_shapes_only.css */
.shape-box {
  float: left;          /* ← habilita shape-outside */
  width: 160px;
  height: 160px;
  margin: 0 18px 12px 0;
}

/* Forma derivada: agrega shape y visual */
.shape-circle {
  shape-outside: circle(50% at 50% 50%);  /* ← flujo del texto */
  border-radius: 50%;                      /* ← aspecto visual */
  background: linear-gradient(...);
}
Sintaxis
circle(50%) = radio o tamaño del círculo (puede ser en px, %).
at 50% 50% = posición del centro del círculo dentro del contenedor.
float: left = sin esto, shape-outside no actúa.
02

ellipse()

Ejemplo con ellipse()

Ideal para elementos con proporciones alargadas o curvas suaves, como logotipos, retratos o ilustraciones ovaladas.

La funciónellipse()permite ajustar el flujo del texto tanto en el eje horizontal como en el vertical, creando una sensación de envolvimiento más natural que un círculo. Al modificar los valores del radio y del centro, puedes simular diferentes perspectivas o alineaciones dentro del diseño.

 .shape-ellipse {
   /* Radio X (55%) y Radio Y (20%) */
   shape-outside: ellipse(55% 35% at 20% 50%);
   background-image: url('img/ellipse.png');
 }
Sintaxis
ellipse(55% 35%) = radio "X" y radio "Y" de la elipse.
at 20% 50% = posiciona el centro de la elipse dentro del bloque.
03

inset()

Ejemplo con inset()

Con shape-outside: inset(0px 80px 0px 0px) el bloque flota a la izquierda pero la silueta del flujo es 80px más estrecha por la derecha. El texto puede entrar en esa franja de 80px, solapando visualmente el borde derecho del bloque.

Prueba cambiando right=80px a 0px para ver la versión sin inset (texto pegado al borde), o a 120px para que el texto entre aún más dentro del bloque.

.shape-inset {
                    /* top  right  bottom left */
  shape-outside: inset(0px  80px   0px   0px);
  /*                        ↑
                    el texto puede entrar
                    en esta franja de 80px
                    desde el borde derecho */
}
Sintaxis
inset(T R B L) — cada valor encoge la silueta desde ese lado.
Con float:left el texto fluye por la derecha, así que R es el valor clave.
04

polygon()

Ejemplo con polygon()

Perfecto para layouts editoriales agresivos. Al usar un polígono, podemos hacer que el texto siga la línea diagonal de una pose corporal (como alguien meditando). También puede añadirse la cantidad necesaria de puntos para poder realizar cualquier tipo de formas, desde triángulos simples hasta siluetas complejas con múltiples ángulos.

En este ejemplo usamos img/meditar.png y recortamos la imagen con clip-path para que coincida exactamente con el flujo del texto (shape-outside). De esta forma, la figura no solo decora la página, sino que se convierte en parte activa de la composición tipográfica. 

.shape-polygon {
                        /* punta  esq. der.  esq. izq. */
  shape-outside: polygon(50% 0%, 100% 100%, 0% 100%);
  clip-path:     polygon(50% 0%, 100% 100%, 0% 100%);
                        /* ↑ mismos puntos en ambas propiedades */
}
Sintaxis
polygon(X Y, X Y, ...) = lista de vértices.
Los valores son % del ancho/alto del bloque (0% = inicio, 100% = fin).
Agrega más pares X Y para crear figuras con más lados.
05

url()

Ejemplo con url()

La opción más potente: el navegador detecta automáticamente el canal alfa (transparencia) de una imagen para crear la forma. Útil para siluetas detalladas.

Cabe destacar que no todos los archivos SVG están preparados para trabajar con shape-outside: url(). En algunos casos, las figuras no utilizan fill="none" para marcar áreas transparentes, sino que aplican colores con cierta opacidad (por ejemplo, menor a 0.4). Cuando ocurre esto, el navegador interpreta la imagen como un bloque rectangular completo y el párrafo fluye alrededor de ese cuadrado, sin reconocer los detalles internos de la silueta.

Usamos img/circles.svg. El texto se ajusta a cada detalle de los circulos sin que tengamos que definir ningún punto manualmente.

 .shape-url {
   /* Usa la transparencia real del archivo SVG */
   shape-outside: url('img/circles.svg');
   background-image: url('img/circles.svg');
   /* shape-image-threshold: 0.3; */   /*controla qué nivel mínimo de opacidad*/
 }
Sintaxis
fill='black' = opaco → ese píxel forma parte de la silueta.
fill='none' = transparente → el texto puede entrar ahí.

shape-margin

Más aire entre el texto y la forma

shape-margin aumenta la distancia entre el borde de la silueta y el contenido que la rodea. Es como un "padding exterior" de la forma, independiente del margin CSS normal. Solo funciona cuando ya hay un shape-outside activo.

Ejemplo de shape-margin

Sin shape-margin

Sin shape-margin el texto queda muy cerca de la silueta. La composición se siente apretada y la forma pierde protagonismo cuando el texto la roza.

shape-outside: circle(50%) está activo aquí.

Con shape-margin

Con shape-margin: 16px el texto respeta un colchón extra de 16px alrededor de la silueta circular. La forma respira y la lectura mejora visiblemente.

Cambia el valor en .shape-margin-on para ver el efecto en vivo.

.shape-margin-base {
  float: left;
  width: 150px;
  height: 150px;
  shape-outside: circle(50% at 50% 50%);
  border-radius: 50%;
}

.shape-margin-on {
  shape-margin: 16px;
}
Sintaxis
shape-margin: 0 = el texto toca casi la silueta.
shape-margin: 16px = 16px de colchón alrededor de la silueta.
No puede superar el margin real del elemento.
